# AI Usage

## какие части делались с AI

ИИ-агент Codex использовался на всех этапах разработки.

## какие решения кандидат принял сам

Решения касательно постановки задач агенту, хода разработки, архитектуры, стэка (помимо обязательного стэка по заданию), генерации типов, наполнения моков, поддержки доступности, визуальной составляющей, фильтров через URL Search Params.

## какие AI-предложения были отклонены

Соответствие проекта FSD-структуре (в ряде слайсов изначально были допущены кросс-импорты), создание типов на основе контракта вместо генерации, поверхностное наполнение моков.

## какие места кандидат проверял особенно внимательно

Особенно внимательно проверял соответствие сгенерированного кода на каждом этапе выданным инструкциям, соответствие существующих фич каждой строчке чек-листа из задания, доступность прохождения базового флоу.

## какие риски остались

Риски, связанные с потенциальным переходом на реальный бэкенд, отсутствие аутентификации, авторизации.

## что бы кандидат улучшил при наличии ещё одного дня

Поработал бы больше над дизайном, проверил бы доступность, добавил темизацию, i18n.
